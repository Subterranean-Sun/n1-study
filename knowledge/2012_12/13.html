逐题理解与辨析

打开对应题目 ↗第 69 题 · すべての公演；隔月（かくげつ）；系列（けいれつ）

サラさんは大学の芸術学部の学生で演劇を勉強している。サラさんが「東西劇場　友の会」の会員になったら、次のどのサービスを受けることができるか。

这是典型N1信息检索题。

Sara：

大学の芸術学部の学生

所以她可以成为：

学生会員

关键权益表：

东西剧场公演

一般会員：10％引
学生会員：15％引

并且前面写：

東西劇場で行われるすべての公演

因此②：

東西劇場で行われる公演をすべて15％割引で観劇することができる。

完全正确。

N1信息题关键字

隔月（かくげつ）

= 每隔一个月一次，也就是每两个月。

千万不要看成：

毎月

系列（けいれつ）

= 系列、关联组织。

直営（ちょくえい）

= 直营。

直営店

併せて（あわせて）

= 一并、同时。

学生証も併せて提示する。

①为什么错？

原文：

会報誌「とうざい」を隔月で送る。

选项：

毎月

偷换频率。

这是信息检索题最常见陷阱之一。

③为什么错？

东西剧场：

所有演出都可以优惠。

但是系列剧场：

一部割引を受けられるものがあります。

只是：

部分演出。

③却说：

系列剧场全部演出都有折扣。

把：

一部 → すべて

这是典型绝对化陷阱。

④为什么错？

商店折扣：

  • 東西劇場直営売店：10％

  • 系列劇場売店：5％

选项说：

两边都是10％。

错误。

打开对应题目 ↗第 70 题 · 一般会員の方；入会費のお支払い；年会費振替用の金融機関口座のご登録

会社員のユアンさんは「東西劇場　友の会」に入会したいと思っている。入会費と年会費の支払いはどのようにするか。

ユアン是：

会社員

并非学生。

所以要按：

一般会員の方

的办理流程。

原文：

事務局で入会費のお支払い

然后：

年会費振替用の金融機関口座のご登録

年会费不是当场付：

ご入会の約二ヶ月後に、登録口座から自動振替

所以：

入会费：在事务局直接支付
＋
年会费：在事务局办理银行账户自动扣款登记

对应③：

事務局で入会費を直接払い、年会費の自動振替の手続きもする。

N1重点商务词

承る（うけたまわる）

谦让语，非常重要。

这里：

ご入会は事務局で承ります。

≈

事務局で受け付けます。

振替（ふりかえ）

金融语境：

账户划转、转账。

自動振替

= 自动从账户扣款。

口座（こうざ）

= 银行账户。

印鑑（いんかん）

= 印章。

持参する（じさんする）

= 携带前往。

印鑑をご持参ください。

引き落とす

= 从银行账户中扣款。

口座から料金を引き落とす。

申し出（もうしで）

= 提出申请、主动提出请求。

退会の申し出

①为什么错？

入会費と年会費を両方事務局で直接払う

这是学生会员的方式：

学生会員は入会費と年会費を事務局で支払う。

ユアン是公司职员，所以不是这一套。

②为什么错？

一般会员并不是去银行柜台：

把入会费和年会费都汇款。

入会费明确是：

事務局で支払う

年会费才走银行账户自动扣款。

④为什么错？

这个选项最迷惑。

事務局で入会費を払う

正确。

但它说：

金融機関で自動振替の手続きをする。

原文并不是“去银行办理”。

而是：

事務局で
年会費振替用の金融機関口座の登録をお願いします

并要求你把：

口座情報＋印鑑

带到事务局。

所以：

手续本身也在事务局办。

因此③。
