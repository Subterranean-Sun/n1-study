打开对应题目 ↗第 69 题 · なるべく高額；～以内に抑える；なるべく

中西さんは35歳の会社員で、CPJカードを申し込むことにした。中西さんは年会費を5000円以内に抑えたいが、海外旅行の保険はなるべく高額なものがよい。中西さんに最も合っているカードはどれか。

这题不能凭感觉，按条件逐个筛掉。

中西さん：

  • 35歳

  • 会社員

  • 年会費 5000円以内

  • 海外旅行保険はなるべく高額

第一步：看年龄

A

30岁以上，可以。

B

18～29岁。

35岁 → 不符合。

C

18岁以上，可以。

D

18岁以上，可以。

剩：

A・C・D

第二步：年费≤5000円

A

10,500円

超过5000 → 淘汰。

C

2,625円

符合。

D

1,050円

符合。

剩：

C・D

第三步：海外旅行保险越高越好

C

最高3,000万円

D

最高2,000万円

因此：

C ＞ D

正解：

3 C

N1实用阅读重点

～以内に抑える

控制在……以内。

費用を5000円以内に抑える。

なるべく

尽量、尽可能。

高額（こうがく）

高额。

ご利用可能枠

信用卡可使用额度。

年会費

年费。

这类N1信息检索题的最佳方法就是：

一个条件一个条件筛掉，不要同时处理所有表格数据。

打开对应题目 ↗第 70 题 · 必ず運転免許証；電気、ガス、水道；現住所（げんじゅうしょ）

会社員の山本さんはCPJカードを申し込むことにした。山本さんは引っ越しをしたばかりのため、運転免許証に書かれた住所と現住所が異なっている。カードを申し込む際、入会申込書のほかに、次のどの書類を提出しなければならないか。

山本さん的情况：

有驾驶证，但是刚搬家。
驾照上的旧地址 ≠ 现在地址。

第一步：他有驾驶证

规则明确：

運転免許をお持ちの方は、
必ず運転免許証

所以必须交：

運転免許証のコピー。

第二步：驾照地址和现住址不同

【注2】规定：

如果身份证明上的地址和申请书现住址不同，还必须附：

能证明现住址的规定材料之一。

可接受材料：

  • 电费

  • 煤气费

  • 水费

  • 社会保险费

  • 纳税证明

因此：

运转免许证 + 水道料金の領収書

成立。

所以4。

1为什么错？

運転免許証のコピーだけ

不够。

因为地址不一致时：

还必须提供现住址证明。

2为什么错？

運転免許証＋住民票

非常容易被骗。

「住民票」确实出现在说明中，但它出现在：

没有驾驶证的人可以选择的本人确认文件。

山本さん：

有驾驶证。

而且地址不一致时追加文件的限定清单a～c里，没有住民票。

因此错。

这是N1表格题经典陷阱：

文件在页面上出现过 ≠ 在当前条件下可以用。

3为什么错？

電話料金の領収書

【注2】写的是：

公共料金
（電気、ガス、水道のいずれか一つ）

没有电话费。

所以电话费收据无效。

4为什么正确？

水道料金

明确属于：

公共料金（電気、ガス、水道）

所以：

運転免許証のコピー
＋
水道料金の領収書のコピー

完全符合规定。

N1重点

本人確認書類

身份证明文件。

現住所（げんじゅうしょ）

现住址。

記載する（きさいする）

记载。

併せて（あわせて）提出する

一并提交。

領収書（りょうしゅうしょ）

收据。

ご希望に添えない

商务日语高频：

可能无法满足您的要求。

这里「添う」表示：

符合、满足。
