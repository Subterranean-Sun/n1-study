按段落整理“提出问题—说明原因—举例—作出判断”的关系。划线句通常需要结合前后文理解，指示词也可能指向前一整段的内容。

回答原因题时区分直接原因与背景；回答内容题时区分作者判断与引用观点。把每个选项的对象、条件、程度和结论与原文逐项比对。

本卷考点与题号

  • 第 49 题：常識とされてきた；見方を少しずらす；再編成する。题解将「自ら問いながら、ものの見方を模索しながら自分自身が変わっていく行為だ。」与原文信息逐项对应，核对对象、条件和结论。
  • 第 50 题：安易に取り込まれる；目を閉ざす；厭世的（えんせいてき）。题解将「常識に縛られずに、これまでと異なる考え方を生み出す行為だ。」与原文信息逐项对应，核对对象、条件和结论。
  • 第 51 题：自分の幼虫と思って。题解将「種をアリの生きた幼虫だと思うから」与原文信息逐项对应，核对对象、条件和结论。
  • 第 52 题：アリの死んだ幼虫のにおいに変わる；種が熟す；はじける。题解将「種からアリの死んだ幼虫のにおいがするから」与原文信息逐项对应，核对对象、条件和结论。
  • 第 53 题：子は親の鏡；もの言い；横からチクリと。题解将「自分で自分を注意しているようなものだから」与原文信息逐项对应，核对对象、条件和结论。
  • 第 54 题：見境なく；貪欲に；いささか。孩子想模仿得一样，但因身体和语言能力尚未成熟，不能完美复制，于是会删减、夸张、自由变形。正是这种偏离产生了新的原创性和个性。
  • 第 55 题。题解将「同じもので多様な使い手に対応すると、そのものの効果に限界が生じる。」与原文信息逐项对应，核对对象、条件和结论。
  • 第 56 题：幅がある；問題性を孕む（はらむ）；負担を抑える。末段转折「しかし」后提出作者主张：不能等问题发生后才考虑平等，而应把它当作产品和服务中始终必要的普通意识。

逐题理解与辨析

打开对应题目 ↗第 49 题 · 常識とされてきた；見方を少しずらす；再編成する

筆者によると、学問とはどのような行為か。

文章结构

  1. “学习”（勉強）常带被动性，而“学问”（学問）是主动发问。
  2. 通过质疑常识、稍微移动观察位置，寻找另一种看法。
  3. 学习并非积累知识，而是重组知识，改变自己的尺度，最终改变自己。

选项判断

  1. 错。原文明确说「学問の『正解』はひとつとは限りません」，并非以寻找唯一正确答案为核心。
  2. 错。独创想法只是可能产生的结果，不是学问行为的全部定义；而且“为获得独创想法而改变看法”把目的说得过窄。
  3. 正确。同时覆盖「自ら問う」「別の見方を見出す」「自分自身が変わっていく」三个核心。
  4. 错。原文特意否定“单纯增加知识”，该项正是被排除的说法。

重点表达

  • 常識とされてきた：一直被视为常识。
  • 見方を少しずらす：稍微移动观察角度。
  • 再編成する：重新组织、重构。
  • 物差しが変わる：判断标准发生变化。
  • 思いがけない：意想不到的。
打开对应题目 ↗第 50 题 · 安易に取り込まれる；目を閉ざす；厭世的（えんせいてき）

学問で「疑う」ことについて、筆者の考えにあうのはどれか。

选项判断

  1. 错。作者并非通过质疑来确定“该信什么”，而是寻找不同视角。
  2. 错。文章说产生不同看法，不是建立一套新的“常识”；“新常识”仍可能变成僵化框架。
  3. 错。作者明确把这种质疑称为「積極的な営み」，并非否定行为。
  4. 正确。「常識に安易に取り込まれない」「少しずらしたところに面白いことを見出す」「創造的で豊かな世界」都支持该项。

重点词语

  • 安易に取り込まれる：轻易被吸收、裹挟。
  • 目を閉ざす：闭眼不看；比喻拒绝思考。
  • 厭世的（えんせいてき）：厌世的。
  • 紡ぎだす：纺织出来；引申为创造、编织出。
  • 営み：活动、实践、日常持续行为。
打开对应题目 ↗第 51 题 · 自分の幼虫と思って

筆者によると、アリはなぜカタクリの種を巣に運ぶのか。

定位原文

アリは種を食べ物として集めるわけではなく、自分の幼虫と思って巣に持ち帰る。

选项判断

  1. 错。虽然种子上有富含脂肪的エライオソーム，但后文推翻了“当作食物”的直觉解释。
  2. 错。没有说是蚂蚁成长必需营养。
  3. 错。不是“像作为食物的幼虫”，而是气味像蚂蚁自己的活幼虫；“餌になる幼虫”是无根据添加。
  4. 正确。直接同义改写「自分の幼虫と思って」。

阅读陷阱

本题先给出“富含脂肪、对蚂蚁有吸引力”的表层信息，再在后段揭示真正机制。N1常用这种先设假说、后修正的结构；答案必须采用后文最终解释。

打开对应题目 ↗第 52 题 · アリの死んだ幼虫のにおいに変わる；種が熟す；はじける

筆者によると、アリはなぜあつめた種を捨てるのか。

定位原文

種がはじけてから24時間もすると、アリの死んだ幼虫のにおいに変わる。

选项判断

  1. 错。不是种子的气味使幼虫死亡。
  2. 正确。种子散发死幼虫的气味，因此被蚂蚁搬出巢外。
  3. 错。变化的是气味，不是颜色。
  4. 错。原文没有笼统说“蚂蚁讨厌的气味”，而是非常具体地说“死幼虫的气味”。

重点词语

  • 種が熟す：种子成熟。
  • はじける：爆裂、迸开。
  • 脂肪分に富む：富含脂肪。
  • 貯蔵する：储存。
  • せっかく～のに：好不容易……却……。
  • 好都合：正合适、对某方有利。
  • 恐れ入る：佩服、惊叹；这里是“真让人惊叹”。
打开对应题目 ↗第 53 题 · 子は親の鏡；もの言い；横からチクリと

「そんな言い方をするもんじゃない」といったら負けだ。とあるが、なぜか。

逻辑

孩子的说话方式来自父母模仿。父母若责备孩子“别那样说”，旁人会指出“这不正是你的说法吗”。因此父母实际上是在责备自己的语言习惯。

选项判断

  1. 错。不是否定成长。
  2. 错。不是承认孩子的反驳在内容上正确。
  3. 正确。孩子复制父母，所以批评孩子等同于批评自己。
  4. 错。重点不是父母降低到孩子水平，而是模仿来源反弹到父母自身。

重点词语

  • 子は親の鏡：孩子是父母的镜子。
  • もの言い：说话方式、措辞。
  • 生意気：自大、狂妄，常形容孩子顶嘴。
  • 横からチクリと：从旁边尖锐地讽刺一句。
  • 揶揄する（やゆする）：揶揄、嘲弄。
  • ～のがオチだ：结果往往就是……，常带讽刺。
打开对应题目 ↗第 54 题 · 見境なく；貪欲に；いささか

こどもの模倣について、筆者はどのように考えているか。

文章核心

孩子想模仿得一样，但因身体和语言能力尚未成熟，不能完美复制，于是会删减、夸张、自由变形。正是这种偏离产生了新的原创性和个性。

选项判断

  1. 正确。「完璧なコピーができない」→「絶妙な逸脱」→「個性的」。
  2. 错。作者并没有批评孩子没抓住本质，反而肯定这种不完美的偏离具有创造性。
  3. 错。孩子不是以取悦大人为目的；大人觉得可爱是结果。
  4. 错。孩子并未有意识地“表达个性”；前文明确说孩子根本不考虑要个性化，只是想和别人一样。

重点词语

  • 見境なく：不加区别、不顾场合。
  • 貪欲に：贪婪地、积极吸收地。
  • いささか：有一点、稍微。
  • 変改する：改变、改造。
  • 誇張する：夸张。
  • 逸脱する：偏离规范、脱离原型。
  • ほほえましい：令人会心一笑、温馨可爱。
打开对应题目 ↗第 55 题

人間が使用するものを作る際の問題点について、筆者が述べていることはどれか。

第一段的二分结构

  • 方案A：让不同体格和能力的人使用同一个产品或环境。
    • 优点：经济上有利。
    • 缺点：效果有局限。
  • 方案B：按不同使用者准备多种尺寸和功能。
    • 优点：能适应多样用户。
    • 缺点：开发耗时、成本上升。

选项判断

  1. 正确。准确对应方案A的缺点「その効果に限界がある」。
  2. 错。“开发耗时”是方案B即个别适配的缺点，不是同一产品适配多人。
  3. 错。个别适配的问题是时间与成本，不是效果看不见。
  4. 错。个别适配本来就是为了让不同人都能使用，不是导致无法平等使用。
打开对应题目 ↗第 56 题 · 幅がある；問題性を孕む（はらむ）；負担を抑える

ユニバーサルデザインにおけるデザインやものづくりについて、筆者が最も言いたいことはなにか。

主旨定位

末段转折「しかし」后提出作者主张：不能等问题发生后才考虑平等，而应把它当作产品和服务中始终必要的普通意识。

选项判断

  1. 部分正确但不够准确。文中当然希望减少不平等感，但作者“最想说”的是设计全过程中持续保持平等意识，而不只是最终做出让大家感觉平等的产品。
  2. 错。作者反对事后才处理问题；该项正是“发生不平等后再查原因”。
  3. 错。虽然实现绝对平等可能困难，但这不是结论重点。
  4. 正确。直接改写「常に必要な普通の意識」。

重点词语与句式

  • 幅がある：差异范围很大。
  • 問題性を孕む（はらむ）：内含问题、潜藏问题。
  • 負担を抑える：降低负担。
  • 不平等感を抱かせない：不让人产生不平等感。
  • 見つめ直す：重新审视。
  • ～ことは間違いない：……无疑。
  • 問題意識が芽生える：问题意识萌生。
  • ～に当たって：在做……之际、在……过程中。
