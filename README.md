2010—2026 年 32 场 JLPT N1 研习资料。包含做题、听力片段定位、逐题讲解、知识专题、考点精编和成绩统计。

- 听力资源：https://Subterranean-Sun.github.io/n1-audio/
- 原始资料与答案归档：https://github.com/Subterranean-Sun/n1-archive/releases/tag/v2026-11-19

手机支持横向滑动主栏目导航。练习和阅读记录保存在当前浏览器，可通过现有 JSON 导入/导出转移，当前没有账号或自动云同步。

本仓库由原离线版复制建立，原目录未改动。线上版单独调整音频 URL、手机导航和使用说明，保留题号、答案、解析、旧锚点和练习缓存键。

## 部署与更新

GitHub Pages 发布源：main 分支，根目录。根目录 .nojekyll 表示直接发布原生 HTML/CSS/JS，无须构建框架。

修改后提交并推送 main，Pages 自动更新。新增卷时把录音放到音频仓库，并在 data/YYYY_MM.js 的 audio.path 使用对应 HTTPS 地址。维护工具包和本地备份不参与发布。

Pages 单站发布体积须保持在 1 GB 以下；录音仓库接近 900 MB 时可为新增音频另建资源项目，保持旧链接不变。

资料来源与校订依据见站内“校订与来源”。本项目不附加对第三方试题、录音或其他原始资料的权利许可。
