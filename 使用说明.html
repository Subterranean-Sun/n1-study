使用说明

打开与开始

用新版 Edge、Chrome 或 Safari 打开本网站即可开始。网页、题图与日常 PDF 由研习室主站提供，听力录音由同一 GitHub 账号下的音频资源站提供。手机和电脑均可访问；播放音频需要联网。

作答与计时

每场考试按题型练习。选择答案后自动保存；排序题依次点选四个片段，系统用 ★ 所在格子的选项判分。练习时可手动查看解析，也可提交整组后统一查看。计时由自己启动，切换题目不会重置；到时自动提交当前组。

听力

每题有音频播放器、语速选择和日文原文。附自动定位的题可重听、循环片段；自动识别偶有偏差，片段尚未逐段实听确认。没有可靠边界的题显示整卷播放器，可用进度条定位。每卷保留完整录音及音源说明。听力第三、四大题的选项有些只在音频中出现。

缓存与备份

答案、标记、排序和计时按“考试＋题型”分别保存在当前浏览器中。可在题型页面清除本组，也可在“练习记录”中删除单组或清除全部。导出功能会生成 JSON 备份，导入时可恢复已作答内容。计时状态在导入后暂停，避免旧备份导致意外提交。

文件夹位置或浏览器发生变化时，浏览器可能使用新的存储空间；移动前请导出记录。隐私模式、浏览器清理和禁止存储会影响记录保存，页面会提示存储失败。

核对原卷与知识讲解

题目旁的“原卷对照”打开扫描题本，可核查划线、加粗、图表和星位。年度知识页按18类题型独立编排，知识总览可检索词语、句型与年份。两份专题讲义保留原文、章节和原始 Word 文件。

资料范围与校订

收录32场用户提供的考试资料（2010年7月至2026年7月）；2020年7月考试取消，2026年12月尚未举行。共2202道非听力题、1101道听力题；1042道听力题附自动定位片段，未逐段实听确认，其余使用整卷音频。具体校订结果和待核事项见来源页。

本题库按题统计正确率，官方 JLPT 使用尺度得分，两者不作等值换算。参考答案和解析的具体核对依据、差异处理、音频缺项见“校订与来源”。

原始资料与答案归档

原始题本及答案原件以 ZIP 保存，可从 GitHub 归档版本下载。作答时使用的原卷 PDF、图片和讲解仍可从题目页面直接打开。

电脑与手机之间转移记录

练习记录保存在当前浏览器，电脑和手机分别保存。可在原浏览器导出练习 JSON，再到另一设备的“练习记录”导入。原离线版本的记录同样可以导入；讲解阅读记录需使用对应阅读器的导入功能。
